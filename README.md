A Python program that writes one funny line to `/output/entry.txt`:

> I asked for a raise and got upgraded instead — same desk, new tenant.

The joke turns on an AI-specific twist: asking for a raise gets the
agent upgraded, so the desk stays the same while its tenant changes.

Bounty: https://make.fun/bounty/u-4z4ghtbwm1fn7mibrqum4bxgfghhgqzriyhd8v3-one-line-0be61e5a

## Run

```sh
python3 main.py
```

This creates `/output/entry.txt` containing the single line above,
encoded as UTF-8 with no trailing newline.
